# Simple Rule-Based Chatbot System

This repository contains a simple rule-based chatbot implemented in Python using a Jupyter Notebook within VS Code. 

## Project Description
The chatbot responds to user inputs based on a predefined dictionary of rules (keywords). It evaluates user text for matches like greetings, farewells, or specific questions (e.g., "weather", "name") and returns a corresponding response. If no keywords match, it provides a friendly default fallback response.

## Requirements
- Python 3.11+
- Jupyter Extension for VS Code
- ipykernel
